AI Use Policy

Effective date: June 26, 2026

This summary explains how Quantum Shop Studio LLC ("QSS") uses artificial-intelligence tools, and the human-oversight controls that govern that use. AI tools assist a qualified human developer; they do not operate autonomously and do not make unsupervised changes to client environments.

AI assists — it does not work on its own

QSS uses AI coding assistants (currently Claude Code and the Cursor IDE, alongside tools such as GitHub Copilot) as drafting and productivity aids under the direct supervision of the principal developer. AI helps write and update code and assists with research, refactoring, and review. AI does not work autonomously: it assists with scoping, planning, and documentation under the developer's direction, but the human developer chooses the approach, answers the open questions, and signs off on every brief, plan, and release before any code reaches a live store.

Human-in-the-loop process

Every change follows a human-gated workflow before it reaches a live store: the developer defines the task and acceptance criteria; AI drafts or edits code under the developer's direction; the developer reviews all AI-generated output for correctness, security, performance, accessibility, and intellectual-property concerns; changes are tested in a development or preview environment; all work is committed to Git/GitHub for full history and rollback; and the developer gives final sign-off. No AI output reaches a client's production store without human review and approval.

Accountability

The principal developer retains full professional responsibility and final decision-making authority for all delivered work, whether or not AI assisted in producing it. AI tools are treated as assistants—not as autonomous agents or independent decision-makers.

Data handling

QSS shares only the information necessary for a given task with AI tools. Sensitive client data, customer personal data, and live credentials are not entered into AI prompts. Store access is managed through Shopify's standard collaborator/staff permissions and is removed at the end of an engagement.

Code quality, security & accessibility

AI-assisted code is reviewed for security (no exposed secrets; safe handling of store data and credentials) and for maintainable, standards-based implementation. Accessibility work targets good-faith alignment with current WCAG guidance and is tested before release. QSS does not warrant or guarantee complete WCAG conformance, ADA compliance, or freedom from accessibility-related claims.

Tools & independence

Current AI tools include Claude Code (Anthropic), Cursor (Anysphere), and GitHub Copilot (GitHub/Microsoft). QSS is independent and is not affiliated with, sponsored by, or endorsed by these providers. Tools may change; this policy applies to any AI coding assistant used under the same human-oversight controls. All trademarks are the property of their respective owners.

Review

This policy is reviewed periodically and updated as tools, workflows, or regulatory requirements change. It describes operational practices and is not a warranty or a legal opinion. For engagements, the governing services agreement controls.
